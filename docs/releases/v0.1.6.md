# Gaori v0.1.6

Gaori v0.1.6 completes the project-wide identity migration across the Go module, CLI binary, local state, deterministic toolchain resolver, documentation, tests, and release metadata.

## Highlights

- Publishes the module as `github.com/irootkernel/gaori` and the standalone binary as `gaori`.
- Uses `.gaori/` for project-local configuration, rules, proposals, and run evidence.
- Uses `GAORI_*` environment variables, `gaori.toolchain.v1` metadata, and `scripts/gaori-toolchain` for deterministic binary selection.
- Aligns CLI output, Markdown summaries, internal identifiers, requirements, traceability records, and operator documentation with the Gaori identity.
- Preserves command exit authority, evidence bounds, redaction behavior, artifact schemas, watcher hashing, and path-containment guarantees.

## Compatibility notes

- Pre-v0.1.6 identity paths, environment variables, metadata keys, and binary names are not compatibility aliases.
- Existing local evidence is not migrated automatically.
- Consumers must update imports, install commands, configuration directories, toolchain metadata, and binary invocations together.

## Known limitations

- Raw logs preserve original evidence and may contain unredacted values. Redaction applies only to derived surfaced artifacts.
- Rule proposals remain local until a maintainer explicitly reviews and promotes them.
- Platform-neutral behavior is tested across the Go suite, with stronger process-group and signal guarantees on Unix than on non-Unix platforms.
