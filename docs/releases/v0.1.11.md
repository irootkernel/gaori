# Gaori v0.1.11

Gaori v0.1.11 adds optional, source-distributed guidance for AI coding agents while keeping Gaori's standalone CLI and evidence contracts unchanged.

## Added

- A concise, copy-ready project instruction template in the root README.
- The `skills/use-gaori/` package with normal workflow guidance and focused lifecycle, authoring, and recovery references.
- Agent-agnostic source and GitHub Raw installation examples. Installing the Gaori binary still does not modify project instructions or install a skill.

## Clarified

- A tagged ad-hoc run can use project extraction rules under `.gaori/tester/rules/` without `.gaori/tester.yaml`; only config-defined redaction and noise filters are unavailable.
- Agents must derive actions from current structured output and artifacts, perform external work before recording it, and avoid blind retries after uncertain mutations.
- Cleanup, cancellation, fixed-path replacement, rule deletion, initialization, and repair-like actions require explicit user intent.
- Gaori remains an optional evidence adapter, not a workflow, session, service, review, test-gate, or acceptance authority.

## Compatibility

- Config schema remains version 2, and run, summarize, excerpt, rule, cleanup, status, summary, parser, and artifact contracts are unchanged.
- The skill is included in the v0.1.11 GitHub source archive but is not copied or activated by `go install`, `make install`, or `make install-toolchain`.

## Verification

- Release verification was explicitly limited to human and JSON version output for v0.1.11.
- The full repository release-readiness gate was not run for this release.

## Known limitations

- Agent runtimes use different instruction and skill-discovery paths; users must select the paths documented by their runtime.
- Original raw logs remain unredacted and may contain sensitive values.
- Gaori has no daemon, running-state heartbeat, session manager, workflow engine, reset command, or general repair command.
