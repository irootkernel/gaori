# Gaori v0.1.19

Gaori v0.1.19 retires the Aquarium development producer source integration. It adds no new CLI or MCP capability.

## Removed

- The aquarium-dev producer Make targets, build helper, and dedicated tests. Normal source builds, installation, CLI/MCP behavior, version output, and both native Gaori skills remain supported. Shared host-manager retirement remains separately owned by Aquarium.

## Compatibility and limitations

- Use the normal Make build, install, and install-toolchain entrypoints for source builds.
- Command exit status remains authoritative; parsers and rules describe evidence only.
- Original raw logs remain unredacted; summaries and surfaced excerpts apply the existing redaction policy.
- Rule proposals remain run-local until reviewed and promoted.
- Binary installation does not install or activate either source-distributed skill.
- Existing resource scaling evidence covers Darwin arm64; Linux scaling remains unmeasured.
- Host-manager retirement, MCP registration, and runtime activation remain separate operations.

## Verification policy

- Master confirmed the existing full make test PASS on the pre-bump candidate and waived a repeated full gate under the patch-only release policy.
- The exact release commit requires make test-prepare, make test-unit, make test-int, isolated installation, and human/JSON version checks before publication.
- make test-e2e and extended release-readiness checks are not rerun. The separate memory campaign and UTM VM verification are not repeated.
