# Gaori v0.1.18

Gaori v0.1.18 bounds memory use across large-log capture, summarize inference, extraction, and excerpt materialization. The source-distributed skills also check that a selected MCP connection belongs to the intended target before starting a run.

## Changed

- Building from source requires Go 1.27.1 or newer.

## Fixed

- Large logs use bounded memory while retaining original raw bytes and the existing command-result and evidence contracts.
- The Gaori skills verify MCP launch bindings, use the explicitly selected CLI target when a binding is uncertain, and retain config overrides in status queries.

## Compatibility

- Command exit status remains authoritative. Parsers and rules describe evidence without changing a command result.
- Original raw logs remain unredacted; summaries and surfaced excerpts apply the existing redaction policy.
- Rule proposals remain run-local until reviewed and promoted.
- The skills are distributed with the source archive and are not installed or activated by the Gaori binary.

## Verification

- Release QA exercises the full v0.1.17-to-v0.1.18 delta against the exact committed candidate, including large-log, skill, MCP, and documentation scenarios.
- The release gate runs the repository's `make test` and separate `make test-memory` campaign, plus isolated installation and version checks.

## Known limitations

- Resource scaling was measured locally on Darwin arm64. Linux resource scaling remains unmeasured.
- Aquarium manager enrollment, host hooks, production activation, and MCP registration are separate operations.
