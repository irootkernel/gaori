# Gaori v0.1.10

Gaori v0.1.10 adds explicit, fail-closed cleanup of completed standalone evidence while preserving project configuration, incomplete evidence, parent-scoped runs, and caller-selected output directories.

## Added

- `gaori clean --older-than <Nd>` for completed standalone runs older than an operator-selected positive whole-day age.
- `gaori clean --all` for all eligible completed standalone history.
- `--dry-run` previews and `--json` result counts for selected, removed, and skipped runs plus selected and removed regular-file bytes.

## Safety

- Cleanup requires exactly one of `--older-than <Nd>` or `--all`. Missing, repeated, conflicting, malformed, zero, negative, or overflowing selectors fail with exit code `2` before filesystem inspection or deletion.
- Selection uses validated UTC standalone directory names rather than mutable filesystem timestamps. Runs at the cutoff and runs stamped in the current `--all` command second are retained.
- Only timestamp-valid directories with a regular top-level status artifact are eligible. Incomplete and unrecognized entries are skipped.
- Every selected tree is inspected before any deletion. Symbolic links, special files, containment violations, and unsafe target changes fail with artifact exit code `3`.
- Cleanup never targets `.gaori/tester.yaml`, rules, proposals, toolchain metadata, `.gaori/runs/scoped/`, or artifacts written through `--output-dir`.

## Compatibility

- Config schema remains version 2, and existing run, summarize, excerpt, rule, status, summary, and artifact contracts are unchanged.
- Raw-log preservation remains mandatory while Gaori creates evidence. An explicit successful cleanup ends retention only for the selected completed standalone runs.
- The parent project or operator still owns retention policy and coordination with evidence consumers. Gaori does not schedule cleanup or infer a default policy.

## Known limitations

- Cleanup does not remove incomplete runs, parent-scoped evidence, caller-selected output directories, or unrecognized local entries.
- Cleanup does not provide a daemon, automatic retention schedule, or cross-process consumer lease. Operators must coordinate cleanup with tools that still need standalone artifact paths.
- Original raw logs remain unredacted and may contain sensitive values until explicitly cleaned.
- The repository has no bundled cross-platform release workflow; platform-neutral tests run locally with additional Unix-specific install and signal coverage.
